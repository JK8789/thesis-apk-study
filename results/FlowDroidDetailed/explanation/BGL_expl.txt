3. Professional interpretation before the LaTeX

For BGL, the current XML is very different from Sberbank.

Dominant pattern in BGL

BGL is dominated by:

SDK logging
consent/privacy SDK behavior
analytics/telemetry-style instrumentation
camera/barcode setup and return flows
some app-to-app launch handling

It is less dominated by deep-link propagation and provider-backed writes than Sberbank.

Relation to declared data collection

BGL declares only:

Files and docs
User IDs
no data shared

This is a much narrower disclosure than Sberbank.

What matches well
Files and docs is supported reasonably well by:
camera/barcode flows
file/media handling
open-document and capture-related app structure
camera/storage permissions
What does not match clearly yet
User IDs is not strongly visible in the representative XML paths
the XML is more dominated by:
Adobe logging
Medallia SDK activity/broadcast flows
OneTrust logging/broadcast flows
so the static evidence does not yet show a clear direct path for user IDs
